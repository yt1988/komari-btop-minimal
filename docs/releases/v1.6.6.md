# v1.6.6

## 中文

### 改进
- 节点详情页会记住所选的延迟时间范围，并对所有节点生效：切换节点、返回列表再进入或刷新页面都保持不变。
- 悬停预取与节点切换器按记住的时间范围预先加载数据。

### 验证
- `npm run check`
- `npm run package`

## English

### Improvements
- The latency range picked on a detail page is remembered for every node: switching nodes, returning from the list and reloading keep it.
- Hover and switcher prefetches load the remembered range.

### Verification
- `npm run check`
- `npm run package`
