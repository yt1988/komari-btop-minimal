# v1.6.0

## 中文

### 新增
- 延迟图加入链路质量显示：每个检测点有一条半透明延迟带（平均值 ±1 个标准差），带越宽表示波动越大。
- 图表下方为每个检测点各加一条丢包带，用该检测点自己的颜色标出丢包时段，丢包越多越亮；隐藏的检测点保留一条变暗的丢包带，切换时布局不变。
- 图例移到图表下方，筛选功能不变，并显示所选时间段内的平均延迟、抖动（`±`）和丢包率（1% 起黄色，5% 起红色）。
- 悬停读数在有丢包时显示该时段的丢包率。

### 修复
- Komari 将丢包的探测记为 -1ms 并计入平均值，导致有丢包的检测点延迟偏低、看起来剧烈抖动。现在平均值与波动只按有回应的探测计算。

### 验证
- `npm run check`
- `npm run package`

## English

### New
- The latency chart shows link quality: each target gets a translucent band (mean ± one standard deviation); a wider band means a less stable link.
- Under the chart each target has its own loss lane, marking lossy periods in the target's color, brighter with more loss. Hidden targets keep a dimmed lane, so toggling never moves the layout.
- The legend moves under the chart, still filters it, and shows each target's mean latency, jitter (`±`) and loss for the selected range (amber from 1%, red from 5%).
- The hover readout adds loss when there is any.

### Fixes
- Komari records lost probes as -1ms and averages them in, which pulled lossy targets' latency down and made them look jittery. Mean and spread now count only probes that replied.

- `npm run package`
