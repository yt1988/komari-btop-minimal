# v1.5.8

## 中文

### 改进
- 离线记录扩展为最近 24 小时：每次离线一行，红点为离线时间、绿点为恢复时间；前一天的时间以 `-` 开头（如 `-13:10`），最多显示 5 行。
- 24 小时内没有离线时，状态仅作文字显示，不可点击。
- 在线时长改为从最近一次恢复上报算起；24 小时内无离线时显示 `1d+`。
- 移除重启时间显示。

### 修复
- 窗口开始前已离线、窗口内才恢复的记录不再遗漏。
- 超过统计窗口的持续离线不再被截断。

### 说明
- 最近 6 小时按每分钟记录统计，更早按 5 分钟记录统计（15 分钟以上的空档才计为离线）。

### 验证
- `npm run check`
- `npm run package`

## English

### Improvements
- Outages now cover the last 24h: one row per outage with a red dot for when it went down and a green dot for when it came back; times from the previous day start with `-` (e.g. `-13:10`), and at most 5 rows are shown.
- With no outage in the last 24h the status is plain text and does not open.
- Online time counts from the last recovery in the report records, or `1d+` with no outage in 24h.
- Removed the reboot marker.

### Fixes
- An outage that began before the window and ended inside it is no longer dropped.
- An outage longer than the window is no longer capped at the window length.

### Notes
- The last 6h use per-minute records; earlier hours use five-minute records, where only gaps over 15 minutes count as outages.

### Verification
- `npm run check`
- `npm run package`
