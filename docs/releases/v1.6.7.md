# v1.6.7

## 中文

- 实时连接和快照请求超时后自动重连。连续 9 秒未收到新快照时，页首标注数据已过期并保留最后一组数值，数据恢复后自动恢复更新时间。
- 节点资料在当前会话通过 Komari 授权后才显示。节点接口返回 401 或 403 时清除本地节点缓存和页面数据，提示重新登录或获取新的分享链接。
- 切换延迟范围时立即显示目标范围的加载状态，并标明仍在显示的旧范围。加载失败后可以重试。
- 上传和下载累计量独立显示。单向额度只依赖该方向的累计量，双向额度仍要求两项都有数据。
- 实时指标和节点资料刷新时复用同一节点的国旗及名称按钮。

## English

- Live connections and snapshot requests now time out and reconnect. After nine seconds without a fresh snapshot, the header marks the displayed values as stale and restores the update time when data returns.
- Node details appear after Komari authorizes the current session. A 401 or 403 from the node endpoint clears cached and displayed node data and prompts the viewer to sign in again or obtain a new share link.
- Changing the latency range immediately shows what is loading and labels any previous range still on screen. Failed loads offer a retry.
- Upload and download totals display independently. One-way quotas use only the relevant direction, while two-way quotas require both totals.
- Live metrics and node metadata refreshes preserve each node's flag and name button.
