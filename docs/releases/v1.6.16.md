# v1.6.16

## 中文

- 修复 Safari 切回标签页时可能留下的空白画面。页面显示暂停、权限检查或连接重试状态，窗口重新获得焦点时也尝试恢复。
- 恢复前继续核验访问权限，并兼容缺少新版取消请求 API 的浏览器。

## English

- Prevent the blank Safari viewport when returning to a paused tab. Show connection status and use window focus as an additional recovery signal.
- Keep the access check on resume and support browsers without newer request cancellation APIs.
