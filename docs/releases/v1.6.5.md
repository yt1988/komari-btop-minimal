# v1.6.5

## 中文

### 新增
- 节点详情页可快速切换节点：点击节点名称，在其下方弹出全部节点列表（顺序与首页一致，显示状态与国旗，当前节点加粗），点选即可跳转。
- 在详情页按钮与延迟图以外的任意位置双击，会在鼠标位置弹出同一列表；靠近屏幕底部时自动向上展开，该处双击不再选中文字。
- 按 Esc 或点击列表外部关闭；鼠标停留在某个节点上会预取其延迟数据。

### 验证
- `npm run check`
- `npm run package`

## English

### New
- Quick node switching on detail pages: clicking the node name opens a list of all nodes under it (node list order, with status and flag, current node in bold); picking one opens its page.
- A double click anywhere outside controls and the latency chart opens the same list at the pointer, flipping up near the bottom edge; double clicking there no longer selects a word.
- Escape or a click outside closes it; resting on an entry prefetches that node's latency.

### Verification
- `npm run check`
- `npm run package`
