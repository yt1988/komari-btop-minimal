# v1.6.14

## 中文

- 固定标签页隐藏后暂停刷新，30 秒后关闭实时连接。切回时先检查访问权限，再立即获取最新快照。
- 首页和详情页只更新实际变化的读数、进度条与状态。详情页默认只请求当前节点，打开节点切换菜单或返回列表时补取完整状态。
- 限制历史图预取并发，切换时取消不再使用的查询。离线记录复用已计算的历史区间。
- 图表读数复用现有元素，将指针移动合并到每帧一次，并通过二分查找定位样本。

## English

- Hidden tabs pause polling and close the live connection after 30 seconds. Returning to the tab verifies access and immediately requests a fresh snapshot.
- Node metrics update only when the displayed values, bars, or status change. Detail pages request the selected node and refresh the full snapshot when opening the node switcher or returning to the list.
- History prefetch is limited and superseded queries are cancelled. Outage history reuses calculated intervals.
- Chart readouts reuse existing elements, batch pointer movement to one update per frame, and find samples with binary search.
