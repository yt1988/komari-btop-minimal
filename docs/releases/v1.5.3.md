# v1.5.3

## 中文

### 更新内容
- 将生产环境的图标分组识别扩展为单个 Unicode pictographic emoji（可带变体选择符），避免未知图标以普通文本方式显示。
- 为 🌍、🌎 和 🌏 添加 “Global nodes” 可访问名称；未知图标提供通用的 “Icon node group” 标签。
- 简化页脚：移除装饰分隔符，并将源码链接文案缩短为 “Btop Minimal”。

### 验证
- `npm run check`
- `npm run package`

## English

### Highlights
- Extended production icon-group detection to a single Unicode pictographic emoji, optionally followed by a variation selector, so unknown icon groups no longer render as ordinary text.
- Added “Global nodes” accessible labels for 🌍, 🌎, and 🌏, with “Icon node group” as the fallback label for other icons.
- Simplified the footer by removing the decorative separator and shortening the source-link label to “Btop Minimal”.

### Verification
- `npm run check`
- `npm run package`
