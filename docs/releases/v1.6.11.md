# v1.6.11

## 中文

- 首页与详情页的流量进度条和上方下载数值共用同一起点。窄屏换行的配额文字也与进度条左边缘对齐。
- 指标菜单依次显示 CPU、MEM、NETWORK、LATENCY。打开节点详情时默认显示延迟。
- 图例和读数统一使用 CPU usage、Memory used、↓ DOWN 和 ↑ UP。读数中的节点离线状态显示为 offline。

## English

- Quota bars now align with the download value above them on both node views. On narrow screens, wrapped quota text starts at the same edge.
- The chart menu lists CPU, MEM, NETWORK, then LATENCY. Node details still open on latency by default.
- Legends and chart readouts use CPU usage, Memory used, ↓ DOWN and ↑ UP. The readout marks offline intervals as offline.
