# v1.5.0

## 中文

### 更新内容
- 强化实时遥测：清理已消失节点报告，避免旧快照覆盖较新的数据。
- 改进 WebSocket 连接状态、重连与请求背压；延迟图支持自动刷新和失败重试。
- 修复部分 API 数据被错误显示为 `0` 的问题，未知字段现在明确显示为不可用。
- 改善移动端流量额度排版、图表交互、状态播报和文字对比度。
- 新增构建检查、发布包校验、CI、开发工具链约束与发布文档。

### 验证
- `npm run check`
- `npm run package`

## English

### Highlights
- Hardened live telemetry by clearing disappeared reports and preventing stale snapshots from replacing newer data.
- Improved WebSocket lifecycle handling, reconnection, request backpressure, latency refresh, and retries.
- Fixed partial API payloads being rendered as misleading zero values; unavailable fields are now explicit.
- Improved narrow-screen traffic layout, chart interaction, status announcements, and text contrast.
- Added build checks, package validation, CI, toolchain constraints, and release documentation.

### Verification
- `npm run check`
- `npm run package`
