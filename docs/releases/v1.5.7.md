# v1.5.7

## 中文

### 新增
- 节点详情页的在线状态后显示当前状态的持续时间（如 `● online 3d4h`、`○ offline 12m`）。
- 点击状态可在下方展开最近 6 小时的离线记录：每次离线一行，显示起止时间与时长，期间发生的重启以 `↻` 标出。
- 延迟图用浅红色标出同一时段的离线区间。

### 说明
- 离线由每分钟负载记录中超过 3 分钟的空档推断，精度约 1 分钟；重启时间来自 agent 的 uptime。

### 验证
- `npm run check`
- `npm run package`

## English

### New
- The node detail status now shows how long the node has been in its current state (e.g. `● online 3d4h`, `○ offline 12m`).
- Clicking the status expands the outages of the last 6h below it, one row per outage with its time range and duration; reboots during an outage are marked with `↻`.
- The latency chart shades the same offline periods.

### Notes
- Outages are inferred from gaps longer than 3 minutes in the per-minute load records, with about one-minute precision; reboot times come from the agent uptime.

### Verification
- `npm run check`
- `npm run package`
