# v1.5.9

## 中文

### 改进
- 离线记录改为悬停在状态上时浮动显示，不再需要点击，也不会推动页面其他内容；手机上轻点状态即可查看。
- 状态只在离线时显示持续时长，在线时不再显示时长。

### 修复
- 页面定时刷新时不再重建顶部区域，悬停中的离线记录不会突然消失。

### 验证
- `npm run check`
- `npm run package`

## English

### Improvements
- The outage list now floats under the status on hover instead of on click, without moving the rest of the page; on phones, tap the status.
- The status shows a duration only while offline; online shows none.

### Fixes
- Periodic refreshes no longer rebuild the page header, so a hovered outage list no longer disappears.

### Verification
- `npm run check`
- `npm run package`
