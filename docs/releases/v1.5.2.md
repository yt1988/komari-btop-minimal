# v1.5.2

## 中文

### 更新内容
- 调整节点分组筛选器：对受支持的首页和全球图标使用原生 emoji 显示，而非文本标签。
- 以降低未选中 emoji 的亮度、恢复选中 emoji 的原始外观来表达筛选状态，取代底部高亮线。
- 为这些图标筛选器加入可访问名称。
- 调整页脚层级和链接外观，使用 “Theme By Btop Minimal” 文案并继承页脚颜色。

### 验证
- `npm run check`
- `npm run package`

## English

### Highlights
- Refined node-group filters to render supported home and global groups as native emoji rather than text labels.
- Indicated filter selection by dimming inactive emoji and restoring the selected emoji’s native appearance, replacing the underline marker.
- Added accessible names for those icon-based filters.
- Refined footer hierarchy and link styling with the “Theme By Btop Minimal” label and inherited footer color.

### Verification
- `npm run check`
- `npm run package`
