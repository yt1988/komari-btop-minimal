# v1.5.5

## 中文

### 修复
- 从节点上移除延迟监测任务后，详情页不再残留以任务 ID 命名的空白监测点（例如 `1`）。监测任务列表加载成功后，延迟图只显示当前分配给该节点的任务；仅在任务列表不可用时才从延迟数据推断监测点。

### 验证
- `npm run check`
- `npm run package`

## English

### Fixes
- Removing a latency task from a node no longer leaves an empty target labelled with the raw task ID (e.g. `1`) on the detail page. Once the ping task list loads, the latency chart only shows tasks currently assigned to the node; targets are inferred from latency data only when the task list is unavailable.

### Verification
- `npm run check`
- `npm run package`
