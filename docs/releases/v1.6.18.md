# v1.6.18

## 中文

- 切换 Safari 标签页时只暂停刷新，已加载的节点列表和详情保持显示。
- 返回标签或网络恢复时在后台更新数据。首次加载由 Komari 确认访问权限，收到 401 或 403 时立即清除节点和历史数据。

## English

- Pause polling on Safari tab switches while keeping an open node list or detail view visible.
- Refresh data in the background on tab return or network recovery. Komari authorizes the first load, and a 401 or 403 immediately clears node and history data.
