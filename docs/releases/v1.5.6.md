# v1.5.6

## 中文

### 修复
- 延迟图中前后都没有相邻数据的孤立采样点（例如节点刚上线或短暂离线前后的单个点）此前不会被绘制，只能在鼠标悬停时看到；现在会以圆点显示。
- Y 轴刻度与网格线对齐：刻度改为根据上限自动生成等距数值，并与网格线使用同一坐标计算，上限不为 300ms 时也不再错位。
- 悬停标记点不再被拉伸成椭圆。

### 验证
- `npm run check`
- `npm run package`

## English

### Fixes
- Isolated latency samples with no neighbour nearby (for example right before or after a short outage) were not drawn and only appeared on hover; they are now shown as dots.
- Y-axis labels now line up with their gridlines: ticks are generated evenly from the ceiling and positioned with the same formula as the gridlines, so they no longer drift when the ceiling is not 300ms.
- The hover marker is no longer stretched into an ellipse.

### Verification
- `npm run check`
- `npm run package`
