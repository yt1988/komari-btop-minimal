# v1.6.3

## 中文

### 性能
- 脚本体积从 83 KB 降至 44 KB（gzip 后从 21.6 KB 降至 15.1 KB）：不再打包 flag-icons 的国家数据，改为构建时生成国旗代码列表。
- 首页预加载 `/api/nodes` 与 `/api/public`，与脚本并行下载。
- 节点列表缓存改存 localStorage，再次打开时立即显示上次的节点列表，并在后台刷新。

### 修复
- 收到第一份实时数据前，节点状态显示为灰色等待，不再短暂闪现红色离线；详情页状态在此之前不显示。

### 验证
- `npm run check`
- `npm run package`

## English

### Performance
- The script drops from 83 KB to 44 KB (21.6 KB to 15.1 KB gzip) by replacing flag-icons' bundled country data with a build-time list of flag codes.
- The page preloads `/api/nodes` and `/api/public` alongside the script.
- The node list cache moves to localStorage, so a new visit shows the last node list immediately and refreshes it in the background.

### Fixes
- Until the first live data arrives, nodes show a grey pending state instead of briefly flashing red offline; the detail status stays hidden until then.

### Verification
- `npm run check`
- `npm run package`
