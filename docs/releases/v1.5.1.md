# v1.5.1

## 中文

### 更新内容
- 以稳定的任务 ID 分配延迟系列颜色；切换时间范围、筛选条件或后端返回顺序不再改变同一目标的颜色。
- 将延迟曲线绘制为连续 SVG 路径，并在缺失、重复或间隔过大的采样点处保留断点。
- 更新终端背景下的延迟配色、曲线圆角以及悬浮读数和探针选择器的颜色标记。
- 在页脚加入安全打开的 Btop Minimal 源码链接，并提供键盘焦点样式。

### 验证
- `npm run check`
- `npm run package`

## English

### Highlights
- Assigned latency-series colors from stable task IDs so a target keeps its color across range changes, filters, and response ordering.
- Rendered latency lines as continuous SVG paths while preserving breaks for missing, duplicate, and over-large sample gaps.
- Updated the terminal-surface latency palette, rounded line rendering, and color swatches in hovered readouts and probe controls.
- Added a safely opened Btop Minimal source link in the footer with keyboard-focus styling.
